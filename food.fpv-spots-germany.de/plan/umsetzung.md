# Wild Food Spot Map

## Beschreibung
entstehen soll eine interaktive leaflet karte für wilde food-spots wie zb:
- nussbäume
- obstbäume
- sträucher
- kräuter
- etc ...


## vorgaben
die projektstruktur ist weitestgehend durch ordner vorgegeben
resgistrieren, spot-estellung usw. sollen erst später implementiert werden.
es soll zuerst die grundkarte mit einem includiertem header enstehen.
der header enthält ein dropdown menü zur navigation

## technologien
- verwende bootstrap per cdn (css, javascript)
- php 8.2
